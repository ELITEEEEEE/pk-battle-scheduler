# PK Battle Scheduler

## Files
- `index.html` — page structure
- `style.css` — layout and visual styling
- `script.js` — calendar and booking behavior

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all three files into the repository root (the main page must be named `index.html`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published link to appear on the Pages settings screen.

## Important note
Bookings are saved in the visitor's browser using local storage. They are not shared between different users or devices. A shared booking list requires a backend/database.
